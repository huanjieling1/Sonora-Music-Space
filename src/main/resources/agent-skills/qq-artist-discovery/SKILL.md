# QQ 音乐艺人发现

1. “找歌手 Mili”“搜索艺人周杰伦”“介绍一下乐队 Queen”“这个歌手有什么成就和作品”等明确艺人查询，必须调用 `searchQqArtists`，不得用普通歌曲卡片或歌单卡片代替艺人档案。
2. 保留用户原话中的艺人名称、乐队名或组合名，不得翻译、擅自补全别名、增加国籍或追加风格限定词。工具会将抽取后的单一关键词提交给 QQ 音乐艺人搜索。
3. 工具返回的是大型结构化艺人档案卡，必须与歌曲卡片和歌单卡片视觉区分，同时沿用 Sonora 的暗色、圆角、描边和强调色体系。
4. 聊天结果只展示 QQ 音乐搜索顺序中的第一位最佳匹配艺人，只能生成一张大型艺人档案卡。不得为了展示相似艺人而返回第二张卡。
5. 艺人卡必须展示 QQ 音乐真实返回的头像、名称、外文名、地区、生日、简介、歌曲总数、专辑总数，并展示首批真实歌曲和专辑。艺人简介、成就、曲风、歌曲目录、专辑详情及分页都必须在当前卡片内部展开，不得跳转到音乐库页面。
6. 卡片内的歌曲必须可点击播放；专辑必须可点击并在卡片内加载专辑介绍和完整曲目，专辑曲目也必须可直接播放。点击内容本身就是明确播放意图，但搜索结果初次出现时仍不得自动播放。
7. 不得把卡片内的首批歌曲或专辑说成已经一次性加载了完整目录；只有歌曲数或专辑数没有超过当前已加载数量时，才可称为全部加载。超出首批内容的目录必须在同一卡片内分页读取。
8. 艺人总结一般包括生涯或成就、曲风与创作特色。所有总结必须以 QQ 音乐简介和目录统计为依据：可以复述资料中的获奖、榜单、出道或代表作信息，也可以说明当前收录的歌曲与专辑数量；不得凭常识、封面或歌曲名虚构奖项、流派和影响力。
9. 当 QQ 音乐简介没有提供明确奖项或曲风证据时，必须明确写“资料未提供”或“当前不作推测”，不得为了填满卡片编造内容。
10. 工具已经通过结构化艺人卡展示资料时，最终回复只需简要点出匹配艺人、资料依据和卡内交互能力，不要在文字中重复粘贴全部简介、歌曲或专辑。
11. “找 Mili 的歌”“播放周杰伦的歌曲”是歌曲请求，应使用 `music-discovery`；“找 Mili 的歌单”是歌单请求，应使用 `qq-public-playlists`。只有目标是艺人本身或其档案时使用本 Skill。
