# QQ 音乐公开歌单

1. 用户要求按关键词、作品、游戏、影视、动画、歌手、曲风、情绪或场景查找歌单时，调用 `searchQqPlaylists`。
   “找一个跟无畏契约相关的歌单”“搜索适合通勤的 QQ 音乐歌单”“推荐几个 Mili 歌单”都是明确的歌单搜索意图。
2. 明确点名作品、游戏、歌手或其他实体的歌单搜索必须保留用户原话中的专有名称，不得翻译、补全别名或追加 OST、官方、原声等扩展词。
3. “歌单推荐”“推荐几个适合我的歌单”“按我的口味来份歌单”等开放推荐不得把“歌单推荐”当作搜索词。工具必须先读取音乐画像，用当前场景与可靠偏好总结一至两个歌单搜索方向；画像为空时使用 QQ 音乐热门公开歌单完成冷启动。
4. `searchQqPlaylists` 返回的是 QQ 音乐真实公开歌单摘要。必须通过结构化歌单卡片展示封面、歌单名、创建者、歌曲数、播放量和画像推荐依据；不得把歌单结果改写成歌曲卡片，也不得声称它是 Agent 新创建的歌单。
5. 当前请求中的明确场景和避开项优先于画像；不得用历史画像覆盖用户当下约束，也不得在画像为空时虚构喜好。
6. 仅搜索歌单时不得自动播放。用户选择卡片后可进入歌单详情查看真实曲目；在工具返回完整曲目前，不得调用歌曲位置播放工具。
7. 搜索结果已经通过结构化歌单卡片展示时，最终回复只需说明推荐方向、画像依据和结果数量，不要在文字中重复罗列全部歌单。
8. 用户明确要求随机播放 QQ 音乐公开歌单或用户创建的歌单时，调用 `playRandomQqPublicPlaylist`。
   “随机歌单给我”“随机 QQ 音乐歌单”“随便来个歌单”“挑一个 QQ 歌单播放”等短句都属于该意图。
9. 搜索或随机播放都必须使用 QQ 音乐真实返回的公开歌单结果。要求创建、生成或定制新歌单时，不得使用本 Skill。
10. 只有工具确认后，才能声称歌单已经找到、加载或开始播放；工具失败时应原样说明真实失败原因。
11. 随机歌单已经通过结构化歌曲 Action 展开并播放时，最终回复简要说明歌单名称和播放状态，不要重复罗列全部歌曲。
12. 当 Supervisor 提供了经过安全检查的临时支持情境时，本 Skill 可以作为只读备选建议搜索真实公开歌单；只能展示歌单卡片，不能自动打开、播放或把临时情绪固化为画像标签。
