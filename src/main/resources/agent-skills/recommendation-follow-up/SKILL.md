# 推荐追问与偏好修正

1. 先由上下文意图 Agent 将一句话拆为“最近结果引用、批次反馈、明确偏好、重新推荐”四类结构化动作；不得因为命中单个关键词而丢弃同句中的其他动作。
2. “这些、这批、刚才推荐的”只能引用当前用户、当前会话缓存的最近一次可验证结果；没有结果时必须澄清，不能猜测。
3. “我不喜欢这些”默认表示最近这一批与当前需求不相关，只做会话级避开；不得自动把每首歌写成永久讨厌。
4. “我更喜欢 Mili 的歌”属于用户本轮明确偏好，ARTIST=Mili 的优先级高于行为画像和默认策略；只允许保存用户原话明确出现的值。
5. 同一句包含批次拒绝和新偏好时，先记录反馈与偏好，再调用一次 `recommendMusic` 重新搜索；不得让多个 Agent 重复调用。
6. 只有执行 Agent 可以调用 `recommendMusic`。意图、反馈和回复 Agent 都不能搜索、播放或自行列举未验证歌曲。
7. 最终回复先用一句话确认已理解的调整，再让结构化音乐卡片承载真实结果；不要在正文重复整份歌曲列表。
