# QQ 音乐榜单与趋势

1. 趋势请求必须调用 `queryQqMusicTrends`，不得降级为把“最近热度最高”等自然语言原样提交给普通歌曲搜索。
2. 官方榜单结果必须标记 `QQ_OFFICIAL`，保留榜单名称、分组、周期、更新时间和原始名次。
3. 热门歌手与歌手热门歌曲是 Sonora 对已持久化 QQ 官方榜单观察的聚合，必须标记 `SONORA_DERIVED_FROM_QQ_CHARTS`；不得称为 QQ 官方热度分或官方歌手榜。
4. 必须显示用户要求的时间窗口和实际覆盖起止日期。数据积累不足一个月时，只能说“月窗口内当前已覆盖的数据”，不得暗示已有完整月度样本。
5. 当前支持巅峰榜、地区榜、特色榜和全球榜等 QQ 实际返回分组；若上游没有对应榜单，要说明未找到，不得编造榜名。
6. “最近哪些歌手比较火”返回衰减聚合后的歌手趋势；“周杰伦最近一个月最火的歌”先解析真实 QQ 艺人，再仅基于其上榜记录排序。
7. 同一请求只允许 Execution Agent 调用一次本工具。Intent、Profile、Evaluator 和 Response Agent 不得直接读取或修改榜单。
8. 结果已通过结构化榜单卡片展示时，正文只用一到两句话交代来源、周期和结论，不重复罗列完整榜单。
